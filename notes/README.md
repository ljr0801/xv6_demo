# 实验笔记

按实验分别记录学习过程，例如 `util.md`、`syscall.md`、`pgtbl.md`。笔记与源码一起提交，方便把思路、失败现象和最终改动对应到 Git 提交。

每次记录可使用下面的模板：

```markdown
# 实验名称

## 目标与当前分支
- 实验要求：
- Git 分支：
- 课程起始提交：

## 思路与源码位置
- 涉及的机制：
- 阅读的函数和文件：
- 计划修改：

## 问题与排查
- 现象或报错：
- 原因：
- 解决办法：

## 验证记录
- 日期：
- 测试的 Git 提交（git rev-parse --short HEAD）：
- 命令：
- 结果与尚未解决的问题：
```

评分结果应记录对应的实际提交和运行命令。只通过编译时写明“编译通过”，不要当作实验评分通过。可摘录关键输出；大量自动生成日志留在容器中即可。

不要在笔记中记录 GitHub Token、SSH 私钥、课程提交密钥或其他口令。
